02 · Rules for the rethink

What Home is for — and what it is not

Home is

A voice journal

How much you spoke. How fast. A hint of recent words. A reason to open the app even when you are not fixing anything.

Home is not

A service panel

“Runtime service”, git commits, and “keyboard is hidden” do not belong on a landing screen. Those are tools. Tools go behind a door.

Status is

Quiet until it matters

If accessibility is off, say so once, clearly. If you are just sitting in WhisperType, do not pretend the bubble is broken.

12 · The APK trap

Allow restricted settings — the real accessibility path

Android 13+ blocks accessibility for sideloaded APKs. Official name: Allow restricted settings, under More on App info (Android Help). The ⋮ item does not exist until the user first tries the Accessibility toggle and sees “Restricted setting — For your security, this setting is currently unavailable.” Our current setup docs never mention this. That is the bug.
